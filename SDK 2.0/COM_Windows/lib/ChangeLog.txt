v3.0.0.0 (Сертифицированная)
	- Добавлены алгоритмы ГОСТ Р 34.10-2015 и ГОСТ Р 34.11-2015; 
	

v3.0.0.1
	- Исправлена ошибка при проверке сертификата методом X509ValidateCertificate() с помощью CRL;
	- Исправлена ошибка при извлечении информации дельта-CRL, CRL, OCSP из сертификата, в котором данная информация отсутствует;
	- Исправлена ошибка при вызове всех методов в VBA, 1C, PHP и в других языках.


v3.0.0.2
	- Добавлена проверка подписи сертификата открытым ключом его "родителя";
	- Устранена ошибка при проверке цепочки корневых сертификатов в методе VerifyData();

v3.0.0.3
	- Для версии x64 был доработана оптимизация компоновщика ;


v3.0.0.4
	- Был доработан механизм проверки сертификата в части сравнения значения "Поставщика сертификата" в поле "Идентификаторе ключа центра сертификатов"  со значением поля "Субъект" в сертификате издателя. 


v3.0.0.5
	- Был доработан механизм подписи хэша (метод SignHash). Добавлен штамп времени при формировании подписи;
	- Исправлена ошибка краха библиотеки во время подписния данных не в формате BASE64, при включенном флаге IN_BASE64;
	- Доработаны ошибки вывода при вызове метода без первичной инициализации;
	- Доработан вывод ocsp-resp в формате BASE64;
	- Добавлен функционал вывода даты отзыва при проверке сертификата на отозванность через CRL;
	
	
v3.0.0.6
	- Доработана проверка срока действия сертификата с учетом часового пояса на компьютере;
	- Доработан вывод сроков действия сертификата с учетом часового пояса на компьютере;	
	- Доработан вывод информации о дате проведения проверки сертификата в методе X509ValidateCertificate() с учетом часового пояса на компьютере;


v3.0.0.7
	- Доработан метод X509CertificateGetInfo() в части вывода информации на кириллице с флагами KC_CERTPROP_ISSUER_DN и KC_CERTPROP_SUBJECT_DN;
	- Устранена ошибка при проверке файла в методе VeriftData().
	
	
 v3.0.1.0
		- Доработан механизм работы с токенами и файловым хранилищем, при переключении с одного типа на другой. 
		
		
v3.0.2.0
