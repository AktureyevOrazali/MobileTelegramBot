# Telegram Companion

Этот репозиторий содержит общее серверное приложение, мобильный клиент на Flutter и новую веб-версию интерфейса оператора, написанную на TypeScript и React.

## Веб-клиент

Веб-приложение находится в директории [`web`](./web) и повторяет функциональность мобильного приложения:

* аутентификация (регистрация и вход);
* просмотр списка диалогов с фильтрами по разделам, БИНам и избранным;
* просмотр деталей чата, обмен сообщениями, управление избранным и удаление переписки (при наличии прав);
* редактирование профиля оператора и смена пароля;
* административный раздел для управления ролями, доступом к разделам и БИНам, а также сброса паролей.

Для запуска web-клиента локально:

```bash
cd web
npm install
npm run dev
```

> Примечание: в среде без доступа к `registry.npmjs.org` установка зависимостей может завершиться ошибкой.

Переменные окружения `VITE_API_BASE_URL` и `VITE_API_TOKEN` позволяют настроить адрес backend-сервера и сервисный токен. Без явного указания используются значения, заданные в мобильном приложении по умолчанию.

## Мобильный клиент

Flutter-приложение расположено в директории [`mobile`](./mobile).

## Backend

Серверная часть на FastAPI находится в директории [`backend`](./backend) и используется как общая точка взаимодействия для мобильного и веб-клиентов.
